# QUESTION 1 \[20 MARKS\]

In this project, we analyze the sentiment of Twitter data using the
**Apache Spark** engine and **Scala** programming language. Apache Spark
is a popular open-source distributed data processing framework capable
of analyzing streaming data on various platforms. It supports several
memory-saving techniques to improve processing efficiency. The primary
reason for using Apache Spark's Machine Learning Library (**MLlib**) is
its ability to process very large datasets efficiently while producing
accurate results.

The project recommends preprocessing Twitter data and applying machine
learning-based text classification with feature extraction techniques to
improve sentiment analysis performance. The entire solution is deployed
on **Amazon Web Services (AWS)**, allowing users to access the system
from anywhere. AWS provides various cloud services such as computing
instances and storage services. In this project, AWS EC2 instances are
used to deploy the application and perform sentiment analysis on an
Ubuntu server.

Spark Streaming extends the core Spark API by enabling scalable,
high-throughput, fault-tolerant stream processing of live data.
Streaming data can originate from multiple sources such as **Kafka**,
**Twitter**, or **TCP sockets**. The incoming data is processed using
high-level operations such as **map**, **reduce**, **join**, and
**window**, before being stored in file systems, databases, or
visualized through live dashboards.
